## [0.3.1] - 2026-09-16

### Added

- 设置 → AI 分析新增「获取模型」：用填写的 Base URL + API Key 拉取可用模型列表（`/models`），填入可编辑下拉框供选择，仍可手输任意模型名
- API Key 输入框新增 👁 显示/隐藏切换（可查看确认是否误输入空格），输入框改深色主题样式
- 默认占位模型名调整为 `deepseek-flash`

### Changed

- AI 分析设置布局对齐：「API Base URL」「Model」「API Key + 👁 + 清空」三行内容等宽；「获取模型」与「测试连接」同行
- ComboBox 控件模板支持可编辑模式，新增 PasswordBox 深色主题样式（与 TextBox 视觉一致）

## [0.3.0] - 2026-09-16

### Added

- **DeepSeek AI 行情分析**：K 线详情窗口新增「✨ AI分析」——点击后窗口向右扩展 320px 侧面板，将本地行情、最近 120 根日K、MA5/10/20、近 5/20/60 日涨跌幅、区间高低与本地量能统计整理为结构化数据交由 DeepSeek 分析，面板结构化展示综合判断 / 摘要 / 趋势结构 / 量价关系 / 压力区域 / 支撑区域 / 风险观察 / 免责声明，支持重新分析与滚动查看。本地数据负责事实，AI 负责解释，不构成投资建议
- 设置中心新增独立「AI 分析」页签：启用开关、API Base URL（默认 `https://api.deepseek.com` 可改）、API Key（DPAPI CurrentUser 加密存储、PasswordBox 不回显、支持清空删除）、Model（默认 `deepseek-chat` 可改）、超时（5–300 秒）、「测试连接」（HTTP 401/403/404/429 等状态中文映射）
- AI 分析结果缓存（SQLite `ai_analysis_cache` 表，Key = 代码 + 最后K线日 + 最新收盘 + 最新成交量 + 模型），同一行情数据命中缓存直接展示，「重新分析」强制刷新；DEBUG 编译下保存脱敏原始响应到本地调试日志（Release 不记录）

### Changed

- AI 侧面板展开时窗口以初始宽度为基础向右扩展 320px，收起恢复；全屏/还原尺寸由状态计算，不再漂移
- AI 面板「前往设置」直接定位到设置中心 AI 分析页签

### Fixed

- AI 返回 JSON 键名风格容错（camelCase / PascalCase / snake_case 全兼容）；System Prompt 强化各字段内容边界（summary 不再吞并趋势 / 量价 / 关键位置内容）
- 压力区域红色、支撑区域绿色（行情终端视觉语义）

## [0.2.3] - 2026-09-16

### Added

- **日K历史回补**：启动后自动检测每只自选的日K缺口，经腾讯历史日K接口（前复权 320 根）后台串行补齐——只插缺失不覆盖已有（避免复权口径污染日常归档）、稳态零请求、单只失败静默下次重试；隔了交易日才开启（如周五忘开周一开）也能补全历史，不再丢数据
- 底部状态栏回补状态指示：「日K回补中 (n/N)…」；完成且有补数时提示「日K回补完成（补 N 天历史）」8 秒后自动消失
- K线图同花顺风格增强：可见区间最高/最低点价格标注（带指向箭头）；十字光标（横竖虚线 + 右侧实时价格标签）；跟手数据面板（日期 / 开高低收 / 涨跌幅 / 成交量，红涨绿跌着色）
- 分时窗口新增最小化、全屏（还原）窗口操作按钮，窗口默认尺寸加大至 720×440

### Changed

- 分时窗口标题行改为分列布局：股票名称完整优先显示，空间不足时压缩代码列，价格与窗口按钮在任何宽度下互不遮挡
- 分时窗口最小化后可在任务栏找回（此前 ShowInTaskbar=False 导致窗口"消失"）

### Fixed

- K线极值标注溢出图表顶部与区间涨跌文字重叠（价格区上下各预留标注空间，极值文字恒在图表内）
- 悬停数据面板半透明底与桌面其他窗口内容混字（背景提升为近乎不透明）

- 状态栏「最后更新时间」后显示产品名与版本号（如 `股票小插件 v0.2.1`，随程序集版本自动更新）

## [0.2.0] - 2026-09-16

### Added

- **日K线自动归档**：每个交易日 15:05 后首个刷新自动落库全自选 OHLC（`daily_kline` 表，零额外请求、幂等可补档），从启用日起积累真实历史行情
- **K线图**：双击行打开的分时窗口新增「分时 / 日K」页签——蜡烛图 + 成交量副图 + MA5/10/20 均线 + 右侧价格轴 / 底部日期轴 / MA 值标注
- **同花顺风格分时图**：价格线 + 分时量能柱（每分钟量，红涨绿跌）+ 昨收虚线固定中央（0%）+ 左轴价格（最高/昨收/最低）/ 右轴百分比（±x%）+ 底部时间轴与当前量值
- **成交额趋势窗口**：右键菜单「📈 成交额趋势」或双击底部量能栏打开——近 60 日柱状（放量红/缩量绿）+ 5/20 日均线 + 统计（较昨增减、均值、60 日排名）
- 行情行信息改为鼠标悬停显示；窗口拖动支持表格行/表头按住移动

### Fixed

- **间歇性 UI 无响应**：走势快照查询移出 UI 线程（此前每 5 秒刷新在 UI 线程同步查库导致透明度/主题切换/调整顺序周期性卡顿）
- **主题切换主窗口不刷新**：主题字典切换后自动重放强调色与透明度覆盖（顶层覆盖刷不随字典切换重算）
- **调整顺序失效**：移动改为物理生效，自动退出表头排序与分类聚集（跨分类移动被弹回的问题）
- 设置中心数值框（字号/间隔/透明度/列宽）显示截断与 ▲▼ 调节器裁切，全部加宽修复

### Changed

- 底部行布局：量值与日期文字同行（窗口最底），时间标签回价格区与量区间隔带
- 深色主题底色与字体渲染优化（Display 像素对齐 + 涨跌文字加粗 + 绿色提亮）

## [0.1.1] - 2026-09-15

### Fixed

- 修复启动崩溃：主窗口 `DropShadowEffect` 的 `Color` 属性引用了 `SolidColorBrush` 资源导致 `XamlParseException`（设置 `UIElement.Effect` 异常，应用无法启动）
- 窗口阴影改为代码容错加载：无 GPU / 远程会话 / 软件渲染环境下 `DropShadowEffect` 创建失败时静默回退为无阴影细边框，保证应用始终正常启动与渲染

## [0.1.0] - 2026-09-15

首个 C# / WPF 重写正式版本（含基线功能与 v1.1 完善）。

### Added

- C# / WPF (.NET 10) 全新重写，功能对齐 Python 旧版（PySide6 UI v1.0.3.10）并全面增强
- 本地 SQLite 数据库（EF Core 10，Code-First 迁移）：设置、自选股、每日成交额历史（自动清理保留 2 年）、
  当日行情快照、预警规则六表（含交易日历）+ 迷你走势；库文件便携优先（`<exe目录>\data\`），无写权限自动回退 `%APPDATA%\StockWidget\`
- 旧版 Python 数据迁移：自动扫描 + 设置中心手动导入 `stock_config.json` / `history_amount.json`
  （自选股、全部界面设置、列宽、历史成交额完整迁移，原文件保留不删）
- 玻璃拟态 UI：无边框圆角 + 渐入投影、深 / 浅 / 跟随系统三态主题热切换、值变动行闪烁与现价 ↑/↓ 箭头动效、
  可选中强调色（橙/蓝/绿/紫/红/青）整套联动、主窗口锁定状态徽章、窗口显隐淡入淡出
- 行情表增强：表头单击排序（升 / 降 / 取消循环，含 ▲/▼ 指示）、指数 / ETF / 个股自动分组（左竖条分组头）、
  键盘 Delete 删除选中、量能金额等宽数字（Tabular Figures）
- 分时迷你走势：行内 Sparkline（当日快照，面积渐变 + 末点光标）+ 双击行打开当日分时图（腾讯分时接口，昨收基准虚线）
- 桌面体验包：个股涨跌幅阈值托盘通知预警（同日同规则去重）、开机自启动（注册表可开关）、
  单实例互斥、窗口越界自动拉回
- 全局热键改用 Win32 `RegisterHotKey`（更稳更省电），支持捕获式录入任意组合
- 节假日休市识别：内置交易日历（`trading_calendar` 表，2025–2026 已确定年份）+ 休市智能抓取
  （休市日跳过抓取、拉长到 600s 探测间隔，恢复交易日自动切回配置间隔）
- 按名称/拼音添加股票：腾讯 smartbox 搜索下拉联动（防抖 300ms、键盘/鼠标选择）
- `ShowDividers` 行间分隔线设置真正生效（旧版为空置配置）
- 单元测试 64 个（代码归一化 / 腾讯响应解析 / 仓储 / 设置 / 热键解析 / 交易日历 / smartbox 解析 / 强调色板）
